# 5-minute setup

1. Install Docker and Docker Compose. About 4 GB RAM for the default (hosted) profile.
2. `git clone https://github.com/mike-gvs/a-team.git && cd a-team`
3. `cp .env.example .env && make up`
4. Open http://127.0.0.1:8080 — the first-run wizard. Keep the stub provider unless you want a live model.
5. Finish the wizard. Talk to Scout (inbox clerk) on the home page. Scout is fictional and never sends mail.
