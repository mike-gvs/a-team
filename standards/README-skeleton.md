# README skeleton (portfolio package standard S4)

Use this heading order in every product README:

1. Title (product name) + one-line problem
2. License and status badges only
3. Centered logo
4. ## What it does (three bullets)
5. ## Screenshot
6. ## Prerequisites (before quick start; list every `# credential` from `.env.example`)
7. ## 5-minute setup
8. ## Run it yourself, or have Gold Valley host and manage it
9. ## AI provider and data handling
10. ## What's stubbed
11. ## Configuration
12. ## Architecture
13. ## Profiles and RAM
14. ## Backups
15. ## Support
16. ## License
17. Gold Valley footer
